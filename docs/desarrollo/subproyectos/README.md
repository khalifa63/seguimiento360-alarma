## Inicio de sesión

1. Leer AGENTS.md, [continuidad general](../CONTINUIDAD.md) y el registro elegido.
2. Verificar HEAD, rama, estado del clon y alcance autorizado.
3. Leer contratos y fuentes relevantes; distinguir hechos de hipótesis.
4. Proponer un plan y criterios de aceptación; respetar autorización de código y operación.

## Cierre de sesión

Actualizar el registro del área y la continuidad general si cambia el estado global. Registrar evidencia, pendientes y próximo paso. Publicar un commit trazable y comprobar la rama remota. No incluir secretos. Consultar [plantilla](PLANTILLA.md).
