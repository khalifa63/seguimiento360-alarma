# Plantilla de continuidad

Copiar únicamente al abrir un subproyecto real. No registrar datos privados.

| Campo | Valor |
| --- | --- |
| ID y alcance | Pendiente |
| Fecha UTC | Pendiente |
| Rama y commit de fuente | Pendiente |
| Build y versión instalada | Desconocidos hasta verificar |
| Cambios y decisiones | Pendiente |
| Pruebas ejecutadas y resultado | Pendiente |
| Evidencia privada | Referencia no sensible o pendiente |
| Riesgos y bloqueos | Pendiente |
| Próximo paso seguro | Pendiente |
| Commit publicado | Consultar Git |

Separar pruebas simuladas, compilación y pruebas físicas. No declarar éxito sin evidencia.
