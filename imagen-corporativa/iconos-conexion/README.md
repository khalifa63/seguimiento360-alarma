# Versiones del icono Conexión

- `conexion-pwa-navy.svg`: recomendada para icono principal PWA.
- `conexion-pwa-light.svg`: alternativa para fondos claros.
- `conexion-monocromo.svg`: impresión, grabado y contextos de una tinta.
- `conexion-adaptativo.svg`: variante de alto contraste para accesos directos.
- `conexion-splash.svg`: pantalla de carga vertical.

Todas son SVG editables, usan la paleta aprobada y fueron validadas como XML.
