# Variantes adicionales — Seguimiento360 Alarma

Seis logos SVG editables, sin imágenes rasterizadas ni fuentes incrustadas. Paleta exclusiva: `#1A3E72`, `#5DC1E1`, `#FFD166`, `#0A182C`; no se usan rojo, candados ni escudos genéricos.

- `logo-wordmark.svg` — wordmark con línea de seguimiento.
- `logo-monograma-360.svg` — monograma circular 360°.
- `logo-senal.svg` — pulso y ondas de señal.
- `logo-radar.svg` — radar de monitoreo.
- `logo-ruta.svg` — ruta con puntos conectados.
- `logo-minimal.svg` — símbolo compacto minimalista.
- `presentacion-variantes.html` — galería de las seis variantes.

Todos incluyen `title` y `desc` accesibles y pueden editarse en Figma, Illustrator, Inkscape o como XML. Validación XML realizada con parser estándar: documentos bien formados.
