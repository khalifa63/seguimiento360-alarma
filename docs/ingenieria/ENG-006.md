# ENG-006 — Diseño mecánico y CAD

Procedimiento para Fusion 360 y SolidCraft; complementa [mecánica y fabricación](MECANICA_FABRICACION.md).

## Paquete por revisión

| Elemento | Control |
| --- | --- |
| Original editable | Aplicación y formato nativo comprobados |
| Ensamblaje | PCB, conectores, cables y fijaciones |
| Exportación | STEP y STL o 3MF según proveedor |
| Plano | Unidades, cotas, tolerancias y revisión |
| Evidencia | Hash de exportación y revisión electrónica compatible |

Nomenclatura propuesta: ID de componente, revisión CAD, tipo de archivo y extensión. Conservar originales en almacenamiento privado. No asumir dimensiones ni tolerancias; medir la placa real y comprobar acceso a conectores, ventilación, RF, montaje y mantenimiento.

## Cierre pendiente

Recibir originales, comprobar formato de SolidCraft, medir piezas, revisar interferencias y aprobar prototipo físico. No hay geometrías nuevas generadas ni archivos CAD aprobados.
