# ENG-007 — Fabricación tercerizada

Procedimiento de liberación y recepción de piezas, aplicable a impresión 3D externa.

## Orden privada

| Campo | Valor inicial |
| --- | --- |
| Orden, componente y revisión CAD | Pendiente |
| Archivo de fabricación y SHA-256 | Pendiente |
| Material, proceso, color y acabado | Acordar |
| Cantidad y tolerancias | Acordar |
| Proveedor, costo y plazo | Privado |
| Muestra inicial y aprobación | Pendiente |

Enviar solo exportaciones aprobadas. No enviar credenciales, firmware ni archivos editables innecesarios. Separar reimpresión de cambio de diseño. Una revisión nueva requiere evaluación de compatibilidad.

## Recepción

Contar piezas, verificar daños y dimensiones críticas contra plano, montar PCB y conectores sin forzar, revisar ventilación y fijaciones, registrar lote y defectos. Aislar no conformes; no liberarlas a instalación. Registrar retrabajo o devolución.

Cierre pendiente: proveedor, orden real, muestra aprobada e inspección de lote. No se ha contratado fabricación.
