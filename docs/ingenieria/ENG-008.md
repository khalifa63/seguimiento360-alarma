# ENG-008 — Infraestructura y Cloudflare

Plan de consolidación basado en [estado histórico](../infraestructura/ESTADO_ACTUAL.md) y [rutas Cloudflare](../infraestructura/CLOUDFLARE_RUTAS.md). No representa una auditoría actual del servidor.

| Área | Inventario a verificar |
| --- | --- |
| Docker | Servicios, imágenes, versiones, volúmenes y redes |
| MQTT | Autenticación, ACL, TLS y exposición de puertos |
| Node-RED | Flujos, credenciales fuera de Git y acceso administrativo |
| Datos | PostgreSQL, InfluxDB, respaldos y retención |
| Cloudflare | Túneles, DNS, origen, TLS y políticas de acceso |
| Web | Portal, PWA, cache y correspondencia con fuente |
| Monitoreo | Salud, alertas y restauración |

## Orden de intervención

1. Inventariar en modo lectura con autorización; no publicar salidas con secretos.
2. Comparar con documentación y registrar brechas privadas.
3. Verificar respaldo y ensayar restauración en entorno aislado.
4. Proponer cambios con alcance, impacto, ventana y recuperación.
5. Ejecutar solo tras aprobación; registrar evidencia y verificar servicio.

No conectar un runner de producción al repositorio público. No ejecutar despliegues, exportaciones de credenciales ni reinicios. Pendiente acceso autorizado al servidor y Cloudflare.
