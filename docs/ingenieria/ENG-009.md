# ENG-009 — Validación de dispositivos

Protocolo de banco para complementar [aceptación](ACEPTACION.md) y SDD. No certifica dispositivos.

## Preparación

Identificar placa, build, revisión y entorno; usar banco aislado, alimentación adecuada y observador. Obtener autorización para cualquier conexión serie o flasheo. Acordar umbrales y escenarios antes de probar.

| Dispositivo | Pruebas mínimas |
| --- | --- |
| HUB | Arranque, vinculación, evento, reconexión |
| Ultrasónico | Distancias conocidas, falsos eventos, pérdida de enlace |
| Cámara | Foto, ráfaga, clip, montaje microSD, recuperación sin borrar |
| Buzzer | Temporización, extensión, parada, pérdida de energía |
| Reed | Apertura, cierre, rebote y reconexión |
| Pánico | Pulsación, recepción extremo a extremo, duplicados, enlace caído |

Registrar por prueba ID, versión, precondiciones, pasos, resultado esperado y observado, evidencia privada y responsable. Clasificar aprobado, fallido, bloqueado o no ejecutado. Repetir tras cambios relevantes.

No usar el botón de pánico como único medio de emergencia durante el prototipo. Pendiente banco físico y ejecución de todos los ensayos de esta revisión.
