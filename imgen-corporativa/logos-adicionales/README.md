# Variantes adicionales de logo

Se generaron cuatro rutas visuales adicionales manteniendo la paleta aprobada:

- `logo-04-radar.svg`: monitoreo y lectura de señales.
- `logo-05-monograma.svg`: versión compacta para app y favicon.
- `logo-06-trayectoria.svg`: seguimiento, ruta y cobertura.
- `logo-07-nodo.svg`: red de activos conectados.

Todos los archivos son SVG editables y XML válidos. Recomendación inicial: probar Radar y Trayectoria en un test de reconocimiento; conservar Monograma para tamaños pequeños. Validar disponibilidad marcaria antes de registrar.
