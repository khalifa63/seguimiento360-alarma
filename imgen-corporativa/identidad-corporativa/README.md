# Seguimiento360 Alarma — aplicaciones de marca

Este paquete contiene layouts SVG editables y plantillas de referencia para implementación inmediata.

## Sistema visual
- Azul naval `#1A3E72` y ciber-azul `#5DC1E1` como base.
- Ámbar `#FFD166` exclusivamente para estados de atención.
- Tinta `#0A182C` y fondo `#F8F9FA`.
- Tipografías: **Space Grotesk** (display) + **Inter** (texto), ambas con licencia OFL y soporte latino extendido.

## Aplicaciones incluidas
- `app-dashboard.svg`: pantalla de monitoreo móvil con estado, mapa y alertas.
- `vehiculo-patrulla.svg`: lateral de vehículo con jerarquía de marca.
- `uniforme-operador.svg`: frente de uniforme con zona de identificación.
- `email-template.svg`, `factura-template.svg`, `presentacion-template.svg`: plantillas editables.

Todos los SVG usan formas y texto editables; abrir en Figma, Illustrator o Inkscape.
