# Plan maestro de ingeniería

Propuesta 1.0.0 para seguimiento360.com. Alcance técnico; excluye comercialización.

## Principios

Conservar la estructura y gobernanza vigentes. GitHub es autoridad de fuentes; verificar instalaciones por separado. No publicar secretos, CAD propietario, binarios privados ni datos operativos. No modificar equipos o servicios sin autorización.

## Ciclo de vida

Requisitos SDD, arquitectura, electrónica, diseño CAD Fusion 360/SolidCraft, firmware, protocolo, infraestructura, seguridad, compilación, flasheo, fabricación externa, ensamblaje, calidad, manuales, publicación, instalación, mantenimiento y retiro seguro.

## Ejecución

1. Consolidar catálogo y fuentes canónicas; revisar privacidad y clones divergentes.
2. Registrar versiones, compatibilidad y continuidad por componente.
3. Extender el procedimiento de compilación y flasheo existente y validar con evidencia.
4. Completar electrónica, CAD, fabricación y manuales de cada nodo.
5. Validar integración, seguridad, restauración y requisitos aplicables antes del piloto.

Consultar [gobernanza](../gobernanza/README.md), [continuidad](../desarrollo/CONTINUIDAD.md), [versionado](../infraestructura/versionado-y-flasheo.md) y [manuales](../manuales/README.md). No duplicar contratos existentes.
