# Archivo histórico

Documentos que ya no son fuente de verdad. Se conservan para trazabilidad; no se mantienen ni se enlazan desde la navegación principal.

## Contenido

## Reglas

1. Nada se borra: se mueve aquí y se marca como obsoleto.
2. Cada documento archivado debe indicar cuál es su reemplazo vigente.
3. No se aceptan PRs que agreguen documentación nueva en `_archivo/`.
